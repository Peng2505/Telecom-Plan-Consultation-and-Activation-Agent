流量包推荐 Agent — 启动步骤
项目目录：D:\LangGraphChatBot-main\04_RagAgent
Python 环境：Anaconda 的 langgraph（不要用 conda activate，本机 PowerShell 会报错）
网页地址：http://127.0.0.1:7860
接口地址：http://127.0.0.1:8012

==================================================
一、每次开机前准备
==================================================

1. 打开 Docker Desktop，等到左下角显示 Engine running（绿色）。

2. 打开 Cursor / PowerShell 终端。不要执行 conda activate langgraph。

3. 进入项目目录：

cd D:\LangGraphChatBot-main\04_RagAgent

4. 确认 .env 里已填写通义 Key（只改这一行，其它保持默认即可）：

DASHSCOPE_API_KEY=你的真实Key

APP_API_KEY 先留空。
DB_URI 不要改成 Key。


==================================================
二、一键部署（推荐：Postgres + API + Gradio 全在 Docker）
==================================================

前提：Docker Desktop 已运行；.env 已填 DASHSCOPE_API_KEY。

cd D:\LangGraphChatBot-main\04_RagAgent
docker compose up -d --build

首次若本地还没有 chroma 集合，api 容器会自动跑 vectorSaveTest 灌库（需联网调 DashScope）。
强制重新灌库：set RUN_INGEST=1 后再 compose up -d（或在 .env 写 RUN_INGEST=1）。

起来后：
- 接口：http://127.0.0.1:8012/health
- 网页：http://127.0.0.1:7860

查看日志：docker compose logs -f api
停止：docker compose down
（加 -v 会删掉 Postgres 数据卷，一般不要加）

说明：会话状态在 Postgres（Checkpointer/Store）；LangSmith 仅做链路追踪（.env 填 LANGCHAIN_API_KEY）。

--------------------------------------------------
【验证一键部署是否成功】（本机已按此跑通）
--------------------------------------------------

1) 看三个容器是否都在跑：

docker compose ps

应看到 ragagent_postgres、ragagent_api、ragagent_web 为 running / healthy。

2) 健康检查（PowerShell）：

Invoke-WebRequest http://127.0.0.1:8012/health | Select-Object -ExpandProperty Content

期望 JSON 里大致有：
"status":"ok"
"postgres":true
"chroma_collection":true

（chroma_collection 为 true 表示知识库已灌入；首次启动 api 可能自动灌库，需等一会再查。）

3) 打开网页：

http://127.0.0.1:7860

注册/登录后发送：经济套餐多少钱？
能正常回复（提到 50 元等）即前端 → API → 模型链路通。

4)（可选）看日志确认无报错：

docker compose logs --tail=80 api
docker compose logs --tail=40 web

全部通过即可认为「Docker 一键部署验证成功」。
日常重启一般用：docker compose up -d
（不必每次 --build；改 Dockerfile/requirements 时再加 --build）


==================================================

==================================================

看到类似下面这行表示接口成功：

可用浏览器或另开终端检查：
http://127.0.0.1:8012/health


【终端 2】网页（这个窗口也不要关）

cd D:\LangGraphChatBot-main\04_RagAgent

看到 Running on local URL: http://127.0.0.1:7860
用浏览器打开该地址，注册/登录后即可聊天。

==================================================
四、可选：评测
==================================================

再开一个终端：

cd D:\LangGraphChatBot-main\04_RagAgent

知识库改过或首次启用稳定 chunk id 后，先重建向量库：

D:\Anaconda\envs\langgraph\python.exe vectorSaveTest.py

只测检索（不需要 API）：

D:\Anaconda\envs\langgraph\python.exe eval\run_retrieval_eval.py

完整分层（接口必须已在 8012 运行）：

D:\Anaconda\envs\langgraph\python.exe eval\run_all.py --label baseline

产物：
- eval\last_retrieval_result.json（Hit@4 / MRR；与线上 RETRIEVAL_TOP_K=4 一致）
- eval\last_faithfulness_result.json（字段命中率 / 数字幻觉率）
- eval\last_result.json（单轮）
- eval\last_conversation_result.json（多轮）
- eval\last_eval_summary_baseline.json（汇总）

改进闭环说明见 eval\IMPROVEMENT_LOOP.md。

模拟业支 curl（main.py 已启动时，同进程接口）：

curl -s -X POST http://127.0.0.1:8012/v1/bss/provision -H "Content-Type: application/json" -d "{\"plan_name\":\"畅游套餐\",\"user_id\":\"demo\",\"campus_student\":false}"

记下返回的 ticket_id，再 GET 两次（第二次才 success）：

curl -s http://127.0.0.1:8012/v1/bss/tickets/这里换成ticket_id



==================================================
五、修改代码后怎么重启
==================================================

- 只改了网页 webUI.py：终端 2 按 Ctrl+C，再执行 webUI.py。main.py 不用关。
- 改了提示词、工具、demoRagAgent.py、main.py：终端 1 按 Ctrl+C 停掉 main.py，再执行 main.py。
- 改了 knowledge/data_plans.md：先跑 vectorSaveTest.py，再重启 main.py。


==================================================
六、停止
==================================================

一键部署模式：
cd D:\LangGraphChatBot-main\04_RagAgent
docker compose down

本机开发模式：
1. 跑 webUI.py 的窗口：Ctrl+C
2. 跑 main.py 的窗口：Ctrl+C
3. 需要关掉数据库时（一般不用每次关）：docker compose down


==================================================
七、曾经踩过的坑（对照用）
==================================================

- PowerShell 里 conda activate langgraph 会报 invalid choice: activate
  解决：用 D:\Anaconda\envs\langgraph\python.exe 启动脚本。

- docker compose 报连不上 dockerDesktopLinuxEngine
  解决：先打开 Docker Desktop 等到 Engine running。

- 缺 psycopg2
  解决：D:\Anaconda\envs\langgraph\python.exe -m pip install psycopg2-binary

- Postgres 报 extension vector is not available
  解决：docker-compose.yml 使用镜像 pgvector/pgvector:pg15，然后：
  docker compose down
  docker compose up -d

- 网页报 messages format / Chatbot type
  解决：已改过 webUI.py，用当前仓库版本即可。

- 聊天没有回复，日志 gbk codec
  解决：提示词已改为 UTF-8 读取，需重启 main.py。

- 模型说「办理成功」
  确认办理后也只是待办 + 模拟业支受理。只有 query_ticket 第二次才可能沙箱 success，不是生产开通。提示词已约束，需重启 main.py。
